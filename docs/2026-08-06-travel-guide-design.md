## 3. 데이터 모델 (localStorage)

**일정 메모**
```js
{ "2026-08-19": "메모 텍스트", ... }  // 날짜(YYYY-MM-DD)를 key로 하는 단순 맵
```

**장소**
```js
{
  id,                                          // uuid
  name,                                        // 장소명
  city,                                        // "골드코스트" | "브리즈번" | "기타"
  category,                                    // "맛집" | "관광지" | "쇼핑" | "교통" | "기타"
  memo,                                        // 자유 메모 (추천 메뉴, 팁 등)
  address,                                     // 선택 입력 — 구글맵 검색 쿼리로 사용
  createdAt
}
```

**체크리스트**
```js
{ id, label, checked }                        // 기본 항목 프리셋 + 사용자 추가/삭제 (카테고리 구분 없음)
```

## 4. 화면 구성

### 하단 탭 3개
📅 일정 · 📍 장소 · 🎒 체크리스트 (스낵PT의 4탭 구조와 동일한 패턴)

### 일정 탭
- 날짜 네비게이션(좌우 화살표, 8/17~8/27)
- 그날의 확정 정보 카드(항공편 또는 숙소 체크인/아웃)
- 자유 메모 textarea (날짜별 localStorage 저장)
- 8/27은 체크아웃-출발 시간 충돌 경고 표시

### 장소 탭
- 상단: 카테고리 칩 필터(전체/맛집/관광지/쇼핑/교통/기타) + 도시 필터(전체/골드코스트/브리즈번/기타)
- 리스트: 카드형, 카테고리 아이콘 + 이름 + 도시 + 메모 미리보기
- 각 카드에 "구글맵에서 보기" 버튼 → `https://www.google.com/maps/search/?api=1&query=<name+address>` 딥링크 (네이티브 앱으로 열림, API 키 불필요)
- 우측 상단 "+" 버튼 → 장소 추가 폼(이름/도시/카테고리/메모/주소), 리스트에서 탭하면 수정/삭제

### 체크리스트 탭
- 기본 준비물 프리셋(여권, 항공권 캡처, 유심/이심, 어댑터, 상비약 등)으로 미리 채워둠
- 체크/추가/삭제 가능, 카테고리 없이 단순 리스트로 시작

## 5. 백업 / 오프라인

- 설정 화면 또는 체크리스트 하단에 JSON 내보내기/가져오기 버튼 (스낵PT와 동일)
- PWA로 홈 화면에 설치 가능, 오프라인에서도 앱 자체는 열림 (구글맵 딥링크만 인터넷 필요)
